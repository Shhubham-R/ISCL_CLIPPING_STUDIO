ISCL CLIP STUDIO - PROFESSIONAL LIVE CRICKET VIDEO & SOCIAL PRODUCTION SUITE
Indian Softball Cricket League (ISCL)
================================================================================

QUICK START (ONE-CLICK LAUNCH):
--------------------------------------------------------------------------------
1. Double-click "START_ISCL_STUDIO.bat".
2. The native desktop application window will open automatically.
3. Paste any YouTube Live stream URL, HLS (.m3u8), or RTMP feed and click "Connect Live".
4. Mark in / out clips on the fly, auto-detect cricket boundaries/wickets with AI, and export in 1080p60!

KEYBOARD SHORTCUTS:
--------------------------------------------------------------------------------
- Spacebar           : Play / Pause Live Video or Active Monitor
- I or [             : Mark In-Point (start of clip)
- O or ]             : Mark Out-Point (end of clip)
- Delete / Backspace : Remove active trim selection
- Left / Right Arrow : Step 1 frame backward / forward

PORTABLE DEPLOYMENT ON OTHER COMPUTERS:
--------------------------------------------------------------------------------
This entire folder is completely standalone and portable.
You can copy or zip this "ISCL_CLIPPING_STUDIO" folder to a USB drive or another Windows PC:
- All required Node.js runtime and Electron binaries are bundled inside.
- All FFmpeg encoding tools and YouTube stream extractors are bundled inside `bin\`.
- No separate software installations or prerequisites are required!
Just double-click "START_ISCL_STUDIO.bat" on any Windows PC.
